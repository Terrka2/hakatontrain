## Заменяемость: три уровня у каждого блока
- **L0 — заглушка.** Работает на fixture, без сети, без ключей, без БД. Пишется первой. После того как у всех блоков есть L0, **сквозной путь работает целиком** — и дальше не ломается никогда.
- **L1 — целевой уровень.** Готовая библиотека или сервис.
- **L2 — если успеем.**

Уровень переключается переменной окружения (`ROUTER=greedy|vroom` и т. п.). Любая ошибка L1 → тихий откат на L0.
**Блок не сделан или сломался → остаёмся на уровне ниже. Продукт беднее, но демо живо.**
«Зависит от» в таблице = «вызывает порт этого блока». Ждать соседа не нужно: у него с первого часа есть L0.

## Как блоки не ломают друг друга
1. Блоки общаются только моделями из `backend/app/contracts/models.py`. Менять файл могут только Арсений и Некит, отдельным PR.
2. У каждого блока — свой список разрешённых путей. CI (`scripts/check_paths.py`) отклоняет PR, который тронул чужое.
3. Общие файлы заморожены после C0: регистрация роутов, конфиг, зависимости. Миграции — только D1.
4. Блок импортирует у соседа только `__init__` (порт), никогда — внутренности.
5. Тесты всех блоков — на одном fixture `backend/app/fixtures/demo_city.json` с разделом `expect`. Эталонные значения посчитаны заранее.

## Порядок сборки
| Фаза | Что | Критерий выхода |
|---|---|---|
| 0 · до хакатона | C0 каркас, CI, доступы, тренировка процесса на одном блоке каждому | чистый клон поднимается у всех пятерых |
| 1 · первые часы | **L0 всех блоков ядра** | сквозной путь на fixture: оператор прошёл → очередь → черновик плана → утвердили → бригада видит маршрут |
| 2 · Friday Exit Gate | L1: D1, B1, B3, B4, B6, B0, F1, F2, F3 | то же на реальном датасете, задеплоено |
| 3 · суббота до 18:00 | L1: B8, F5, B5, L1, D2, L3 (+MCP), L2, F4 | демо-сценарий из CONCEPT.md проходит целиком, включая «не могу» → план v2 |
| 4 · после feature freeze | только починка, метрики, полировка F6 | — |
| доп. | X1 → B7 → F7 | только по решению Арсения, когда фаза 3 закрыта |

**Режем в таком порядке, если горим:** L2-уровни → D2 на эмбеддингах (остаётся tfidf) → L2 assistant на LLM (остаётся keyword-режим) → MCP-сервер (остаются внутренние инструменты) → VROOM (остаётся greedy).
**Неприкосновенно:** B0, B3, B4, B6, B8, F1, F2, F3, F5 — четыре вопроса задачи плюс цикл «оператор → руководитель → бригада».
