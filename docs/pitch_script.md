# Питч: Платформа гражданских инициатив и афиша города

## 1. Проблема (30 сек)
Жители не знают, как повлиять на развитие района, а их идеи дублируются и теряются в чатах. Малый бизнес не имеет простого канала связи с городской повесткой.

## 2. Решение (30 сек)
Единая платформа: инкубатор идей с дедупликацией и голосованием + актуальная афиша событий.

## 4. Эффект для города (30 сек)
Экономия бюджета на соцопросах, рост вовлеченности, прозрачный фильтр лучших идей для мэрии.
