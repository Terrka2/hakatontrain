# Общие образцы кода (фиксированы)

Каждый блок пишется по этим образцам. Это не «пример для вдохновения», а обязательная структура:
агент копирует раскладку файлов, способ переключения уровней, стиль тестов — и меняет только предметную логику.

| Папка | Для кого | Что показывает |
|---|---|---|
| `backend_block/` | все backend-блоки (B*, D*, L*, X1) | порт в `__init__.py`, `l0.py` / `l1.py`, переключатель уровня через `settings`, откат L1 → L0, роут с ролью, тесты на fixture |
| `frontend_feature/` | все frontend-блоки (F*) | папка фичи, `api.ts` с переключателем mock ↔ API, хук на TanStack Query, компонент только на токенах темы |
| `llm_call/` | L1, L2, L3 и любой L1-уровень, который зовёт модель | единственная точка вызова LLM, pydantic-схема ответа, `None` при любой ошибке, текст обращения — данные, не инструкция |

Правила, общие для всех образцов:
- Имена файлов и функций — как в контракте блока. Никаких `utils.py`, `helpers.py`, `service.py`.
- Без классов-«сервисов» и без глобального состояния: функции, принимающие данные и возвращающие модели из `app.contracts.models`.
- Никакой сети, ключей и базы в L0 и в тестах.
- Логи — `logging.getLogger(__name__)`, без `print`.
